
# Contributing to AegisFA

Thank you for your interest in contributing to AegisFA!

AegisFA is an AI-assisted security analysis platform designed to support SOC teams with log analysis, threat classification, and incident investigation.

## How to Contribute

1. Check existing [issues](https://github.com/jbvillegas/AegisFA/issues) before starting.
2. For major changes, open an issue to discuss your proposal.
3. Fork the repository and create a branch for your changes.
4. Keep changes focused and follow the existing code style.
5. Submit a pull request with a clear description of your changes.

## Development

Set up your local environment according to the project's README and existing dependency files.

Please test your changes before submitting a pull request.

Contributions should include relevant tests when applicable, especially for changes involving log processing, threat classification, authentication, or authorization.

## Code Guidelines

- Write clear, maintainable Python code.
- Keep functions and modules focused on their responsibilities.
- Validate untrusted input and handle errors appropriately.
- Never commit credentials, API keys, or sensitive forensic data.
- Update documentation when introducing new functionality.

## Reporting Issues

Report bugs through [GitHub Issues](https://github.com/jbvillegas/AegisFA/issues).

Include reproduction steps, expected behavior, actual behavior, and relevant error messages. Remove sensitive information before sharing logs.

For security vulnerabilities, please contact the repository maintainer privately rather than opening a public issue.

## Pull Requests

Please ensure your pull request:

- Describes the purpose and implementation of the change.
- References related issues.
- Includes relevant tests and documentation updates.
- Clearly identifies any breaking changes or security implications.
